# MOXI 墨兮 退换货政策

### 退货条件
1. 商品需保持未穿着、未洗涤状态
2. 商品吊牌、包装完整
3. 不影响二次销售
4. 自签收之日起 7 天内申请

### 退货流程
1. 联系在线客服，说明退货原因
2. 客服审核通过后，提供退货地址
3. 将商品寄回（请保留快递单号）
4. 仓库收到商品并确认无误后，安排退款

### 退款时间
- 微信/支付宝支付：1-3 个工作日
- 银行卡支付：3-7 个工作日
- 退款原路返回

### 换货政策
1. 同款商品不同尺码/颜色可换货
2. 换货需在签收后 7 天内申请
3. 寄回运费由顾客承担，寄出运费由 MOXI 承担
4. 换货仅限一次

### 质量问题
1. 收到商品 7 天内发现质量问题，可申请退换
2. 请拍摄质量问题照片联系客服
3. 质量问题退换货运费由 MOXI 承担
4. 质量问题包括：破洞、染色、严重脱线、明显污渍

### 不支持退换的情况
1. 商品已穿着、已洗涤
2. 吊牌、包装缺失或损坏
3. 定制商品、贴身衣物（如内衣、袜子）
4. 特价商品（标注"不退不换"）
5. 超过 7 天退换时效

### 大促期间
618、双11、双12等大促期间：
- 退货时效延长至 10 天
- 退款到账时间可能延长 2-3 个工作日
